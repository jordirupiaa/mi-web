# Dónde poner las fotos reales

Copia los archivos en estas carpetas con estos nombres exactos (jpg, png o webp — cualquiera vale, pero mantén el nombre base). Cuando estén, avísame y las conecto en el código.

## public/images/rooms/  — una foto por tipo de habitación

Estos son los 6 alojamientos que ya existen en la base de datos. El nombre del archivo debe coincidir con esta lista:

- `single-room.jpg` — Single Room
- `twin-window.jpg` — Twin Room with Window
- `twin-balcony.jpg` — Twin Room with Balcony
- `triple.jpg` — Triple Room
- `quadruple.jpg` — Quadruple Room
- `penthouse.jpg` — Penthouse Apartment

## public/images/hotel/  — fachada y zonas comunes

- `hero.jpg` — la foto grande de portada (home). Horizontal, buena calidad, la más "bonita" que tengáis.
- `facade.jpg` — fachada / entrada del hotel
- `lobby.jpg` — recepción o zona común interior
- `terrace.jpg` — terraza / balcón / exterior con vistas (si hay)

## public/images/location/  — entorno (opcional, solo si tenéis fotos propias)

- `beach.jpg`, `street.jpg`, etc. — cualquier foto vuestra de la playa o calle cercana al hotel. Si no tenéis, no pasa nada, esa parte se queda con las fotos genéricas de momento.

No hace falta que estén todas para empezar — conecto las que vayan llegando y dejo el resto con el placeholder actual hasta que lleguen.
